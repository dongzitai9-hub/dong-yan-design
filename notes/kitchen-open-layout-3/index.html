Kitchen Layout Note

厨房要不要打开？先看餐厨怎么交流

开放式厨房和封闭式厨房之间，并不只有二选一。对中国家庭来说，更重要的是让做饭的人、吃饭的人和路过的人能自然发生交流。

董揅札记 · 厨房布局

基于资料提炼和设计整理的餐厨关系札记，案例人物均做匿名化处理。

Opening Thought

厨房不是非封即开，中间还有可分可合

讨论厨房时，最容易陷入“封闭”和“开放”的二选一。但真正影响生活的，是家里怎么做饭、谁在做饭、做饭时是否需要和家人说话，以及重油烟时能不能及时隔开。

所以这篇先把问题放回生活场景：让厨房有边界，也有交流；能合上，也能打开。

Middle Choice

第一步：别急着拆墙，先找“可分可合”的位置

甲客户的厨房面积不大，采光也一般。餐厅和厨房之间的墙体不是承重墙，理论上可以完全拆掉。但家里日常做中餐，老人也会下厨，如果一下子做成全开放，油烟和台面凌乱都会变成长期压力。

这个时候，比较稳的做法不是直接拆光，而是在餐厨之间打开一个“沟通界面”。它可以是室内窗，也可以是移门。平时打开，让做饭的人能看到餐厅、听到家人说话；爆炒时关上，把油烟和声音留在厨房里。

设计师判断 可分可合厨房的价值，不是为了做一个漂亮的玻璃框，而是让空间能随场景变化：早餐、备菜、聊天时打开；重油烟烹饪、收拾残局时合上。
Interior Window

室内窗不是装饰，它要同时处理视线和遮乱

餐厨之间开窗，最容易被忽略的是窗台高度。窗开得太低，餐厅一眼看到水槽、抹布和电饭煲，厨房会显得凌乱；窗开得太高，交流又不够顺畅。比较舒服的做法，是让窗台比厨房台面略高一些，既能保留看见彼此的视线，又能挡住台面上的零碎。

如果厨房本身采光弱，高窗会让空间更明亮，但可能牺牲一部分吊柜。这个取舍要回到收纳总量里算，不能只看单面墙。

Sliding Door

第二步：用移门替代实墙，让小厨房借到大空间

乙客户家的厨房原本采光弱，封闭后显得小。改造时用多轨移门替代实墙，平时全打开，厨房像起居空间的一部分；炒菜时拉上，仍然保留封闭厨房的实用性。

这里有一个很重要的心理尺度：同样是 70cm 的走道，如果两侧都是实墙，人会觉得压迫；如果一侧是通透玻璃，身体感受会轻松很多。小厨房想做 U 型布局时，这种“借空间感”的办法很有价值，但前提是移门轨道、柜门开启和人员通行都要一起核算。

Micro Circulation

水槽附近，最容易形成交流中心

在洗、切、炒三件事里，炒菜最需要专注，也最容易产生油烟；洗菜、备菜反而更适合聊天。把水槽放在餐厨之间的界面附近，做饭的人抬头就能看到家人，家人也能自然靠近帮忙。

如果水槽柜还能承担一点“迷你岛台”的作用，两侧都能进出，动线就会从单向变成微洄游。小户型不一定要追求大岛台，但可以争取一个小而有用的操作节点。

Dining Kitchen

第三步：餐厨合一不是大就好，而是要有人愿意坐下来

丙客户更喜欢做饭，也常邀请朋友一起吃喝。他家的重点不是把厨房藏起来，而是把厨房和餐桌合成一个生活场。柜体长度增加后，收纳、电器和操作面都更完整；中部增加水槽后，多人备菜、洗菜、包饺子、做披萨都能围绕餐桌发生。

但餐厨合一也有一个常见误区：只做一个高吧台，看起来很有氛围，真正能坐下来的时间却很短。高脚椅没有稳定支撑，脚不容易落地，适合短暂停留，不适合作为家里的主要餐桌。想让家人和朋友真正坐得住，桌面高度、椅背、腿部空间和视线关系都要一起考虑。

Before Layout

先看生活画像，再判断餐厨关系

餐厨合一不是按面积大小简单决定，而是先看居住人数、做饭频率和会客习惯。一个人住、爱下厨、朋友常来，餐桌就可能成为家的中心；如果家里多人轮流做饭，厨房边界和收纳秩序就要更谨慎。

Three Keywords

最后看三个关键词：柜台、水槽、稳坐

可分可合只是手段，交流才是目的。不是所有玻璃移门、吧台和西厨都能带来交流，关键要看人在空间里的动作是否真的会相遇。

  • 柜台内侧有人操作，外侧有人停留，视线自然相遇。
  • 水槽洗菜、洗手、备餐这些动作更容易边做边聊。
  • 稳坐椅子舒服、脚能落地，人们才愿意真的留下来。
Design Conclusion

分合只是手段，交流才是目的

所以，厨房要不要打开，不能只看图片好不好看。董揅设计更建议先问四件事：家里谁做饭，做什么菜，做饭时想不想和家人交流，以及餐桌是不是真的有人愿意坐下来。

答案清楚以后，封闭、开窗、移门、餐厨合一，才会从风格选择变成生活选择。
